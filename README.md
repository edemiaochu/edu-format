# edu-format — 数学讲义批量格式化工具

将目录下所有 Word（.docx）文件统一排版为标准中文数学讲义格式，**原文件保持不动**，结果输出到独立目录（默认 `<输入目录>/formatted/`）。

## 安装

```bash
pip install -r requirements.txt   # 仅需 python-docx
```

## 使用

**方式一：交互模式（推荐）** —— 双击 `启动格式化.bat`，或运行：

```bash
python format_handout.py
请输入页眉文字（直接回车 = 沿用原页眉）：八年级数学讲义     # 不需要页眉就直接回车
请输入讲义文件夹路径（或单个 .docx 文件；直接回车退出）：D:/讲义
```

- 路径可以直接粘贴（自动去掉复制地址时带的引号）
- 一个文件夹处理完后可继续输入下一个，直接回车退出

**方式二：命令行带参数**

```bash
python format_handout.py <目录或.docx文件> [-o 输出目录]

# 示例
python format_handout.py D:/讲义               # 输出到 D:/讲义/formatted
python format_handout.py 七年级下 -o 已排版     # 输出到 七年级下/已排版
python format_handout.py 第3讲.docx            # 单文件，输出到 formatted/
python format_handout.py D:/讲义 --header "八年级数学讲义"   # 统一设置页眉文字
```

## 默认格式规范

| 元素 | 识别规则 | 格式 |
|---|---|---|
| 讲义标题 | 文档首个非空段落（如“第3讲 勾股定理”） | 黑体 小三，居中 |
| 一级标题 | “一、…”“第2章…”“第3讲…” | 黑体 四号，居中，段前/段后 12pt |
| 二级标题 | “（一）…”“1.1 …”，以及“练习”“作业”“知识梳理”等板块名整行 | 黑体 小四 |
| 例题 | “例1 …”“例题 2 …” | “例N”前缀黑体加粗，段落顶格 |
| 题目标签 | “【典例1】…”“【变式1】…”“【易错点】…”等【】指示标签 | 标签华文行楷加粗，段落顶格，标签后题干仍为正文格式 |
| 前导词 | “解：”“证明：”“分析：”“注意：”等 | 前导词自动加粗 |
| 正文 | 其余段落 | 中文宋体 + 西文 Times New Roman，五号，1.5 倍行距，首行缩进 2 字符，两端对齐 |
| 页面 | — | A4 纵向，上下边距 1.6cm、左右 1.7cm |
| 页眉页脚 | — | 华文行楷 10 号；页脚居中“第 N 页”；页眉默认沿用原文内容并统一字体，设置了页眉文字则替换为统一页眉（居中、带下框线） |

其他行为：

- 自动删除多余空行；各级标题设置大纲级别（Word 导航窗格可见）
- 表格、图片、公式（OMML）原样保留；正文中原有的加粗/斜体/颜色等强调保留
- 原文档里用 Word 标题样式（标题 1/标题 2）设置的段落会被对应识别
- 旧版 `.doc` 文件请先在 Word 中另存为 `.docx`

## 自定义格式

所有格式参数集中在 `format_handout.py` 顶部的**「格式配置」**区（字体、字号、行距、页边距、板块名词表等），直接修改后运行即可，无需改动其他代码。
